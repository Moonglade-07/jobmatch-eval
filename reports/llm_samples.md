# LLM Explanation Quality: Qualitative Samples

*Programmatic checks against job text; no human or LLM judge*

This document contains qualitative samples of explanations generated by `gemini-3.1-flash-lite` (prompt `explain-v1.0`) over the top-5 retrieved postings for candidate profiles from BM25 Only retrieval.

Groundedness is evaluated programmatically against the job description text using boundary-safe regex (main) and strict exact substring matching. No LLM judge was used.
