# 💼 JobMatch AI — Search & Conversational Agent Demo

> **Evaluation Disclaimer**: Demo on a 3,000-posting sample of LinkedIn postings; relevance labels in the evaluation are rule-based and unverified.

Interactive Streamlit demonstration of the `jobmatch-eval` search and multi-turn conversational agent pipeline.

---

## 📌 System Architecture

1. **Job Search & Grounded Explanations**:
   - Multi-strategy retrieval over 3,000 LinkedIn postings:
     - **BM25**: Lexical token matching.
     - **Dense**: ChromaDB bi-encoder vector search (`sentence-transformers/all-MiniLM-L6-v2`).
     - **Hybrid RRF**: Reciprocal Rank Fusion ($k=60$).
     - **Cross-Encoder**: Deep re-ranking (`cross-encoder/ms-marco-MiniLM-L-6-v2`) — disabled in cloud deployments with constrained RAM (`DISABLE_CROSS_ENCODER=1`).
   - Match explanations generated by `gemini-3.1-flash-lite` with literal job description groundedness verification (91.7% / 94.2% adj.) and visible fallback indicators.

2. **Conversational Search Agent**:
   - Multi-turn job search assistant powered by Gemini function calling (`search_jobs`, `get_job_details`, `refine_filters`).
   - Persistent session memory holding location, seniority, technical skills, and user dislikes across turns.
   - Evaluated across 10 scripted multi-turn scenarios (28 total turns) achieving **90.0% behavioral pass rate** and **100.0% memory retention** (23/23 checks).

---

## 🛡️ Quota Protection & Security

- **Zero Secret Exposure**: `GEMINI_API_KEY` is loaded securely from Space secrets and is never exposed to the client browser or application logs.
- **Abuse Prevention**:
  - **Per-Session Cap**: Maximum 20 requests per user session.
  - **Daily Global Cap**: Maximum 200 requests per day across all visitors.
  - Once exhausted, the application gracefully degrades to rule-based heuristic extraction with a clear UI banner.
